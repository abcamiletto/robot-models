# G1

The Unitree G1 body has 40 skeleton joints and 29 `body_pose` coordinates,
without hands.

Source: LeRobot `unitree-g1-mujoco`, derived from Unitree's BSD-3-Clause description.
Assets download automatically; see [asset setup](../index.md#assets).

A manual `model_path` is a directory with `g1.xml` and its meshes.

```python
from robot_models.humanoids.g1.numpy import G1

model = G1()
params = model.get_tpose()
```
