# G1

G1 is the Unitree G1 humanoid (29-DoF body without hands). Its skeleton has 40 joints, one per MJCF body, and `body_pose` has 29 hinge coordinates.

## Setup

The assets come from LeRobot `unitree-g1-mujoco`, derived from Unitree's BSD-3-Clause description. They download on first use from the
[`abcamiletto/robot-models`](https://huggingface.co/abcamiletto/robot-models)
Hugging Face repository, with the upstream license and a list of changes. To prefetch them:

```bash
robot-models download g1
```

A manual `model_path` is a directory with `g1.xml` and its meshes.

## Usage

```python
from robot_models.g1.numpy import G1

model = G1()
params = model.get_tpose()
```
