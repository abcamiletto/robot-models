# H1

The original Unitree H1 has 20 skeleton joints and 19 `body_pose` coordinates.

Source: MuJoCo Menagerie `unitree_h1` (BSD-3-Clause).
Assets download automatically; see [asset setup](../index.md#assets).

A manual `model_path` is a directory with `h1.xml` and its meshes.

```python
from robot_models.humanoids.h1.numpy import H1

model = H1()
params = model.get_tpose()
```
