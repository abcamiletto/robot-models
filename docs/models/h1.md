# H1

H1 is the original 19-DoF Unitree H1 humanoid. Its skeleton has 20 joints, one per MJCF body, and `body_pose` has 19 hinge coordinates.

## Setup

The assets come from MuJoCo Menagerie `unitree_h1` (BSD-3-Clause). They download on first use from the
[`abcamiletto/robot-models`](https://huggingface.co/abcamiletto/robot-models)
Hugging Face repository, with the upstream license and a list of changes. To prefetch them:

```bash
robot-models download h1
```

A manual `model_path` is a directory with `h1.xml` and its meshes.

## Usage

```python
from robot_models.h1.numpy import H1

model = H1()
params = model.get_tpose()
```
