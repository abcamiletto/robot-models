# H1

H1 is a rigid articulated Unitree H1 model with STL link meshes attached to a
20-joint skeleton and 19 actuated hinge joints.

## Setup

H1 downloads automatically on first use from the
[`abcamiletto/robot-models`](https://huggingface.co/abcamiletto/robot-models)
Hugging Face repository. The assets come from the MuJoCo Menagerie
[`unitree_h1`](https://github.com/google-deepmind/mujoco_menagerie/tree/main/unitree_h1)
model under the BSD-3-Clause license, which is included with the hosted assets.
To prefetch the assets:

```bash
robot-models download h1
```

When passed manually, `model_path` should contain `h1.xml` and
`meshes/*.stl`.

## Notes

H1 does not define `skin_weights`. Use `forward_links()` for link transforms and
`forward_meshes()` for renderable meshes.

H1 has no wrist or foot bodies, so `Joint.LEFT_WRIST`, `Joint.LEFT_FOOT`, and
their right-side counterparts are not mapped.
