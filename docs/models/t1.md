# T1

T1 is a rigid articulated Booster Robotics T1 humanoid with STL link meshes
attached to a 24-joint skeleton. It has 23 hinge degrees of freedom: head (2),
arms (4 per side), waist (1), and legs (6 per side).

## Setup

T1 downloads automatically on first use from the
[`abcamiletto/robot-models`](https://huggingface.co/abcamiletto/robot-models)
Hugging Face repository. The assets come from the
[MuJoCo Menagerie `booster_t1`](https://github.com/google-deepmind/mujoco_menagerie/tree/main/booster_t1)
model (Apache-2.0). To prefetch the assets:

```bash
robot-models download t1
```

When passed manually, `model_path` should contain `t1.xml` and
`meshes/*.stl`.

## Notes

The rest pose has the arms stretched sideways, so `get_tpose()` equals the rest
pose. `get_apose()` lowers both arms by 45 degrees with the shoulder roll
joints. T1 does not define `skin_weights`. Use `forward_links()` for link
transforms and `forward_meshes()` for renderable meshes.
