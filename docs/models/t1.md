# T1

The Booster Robotics T1 has 24 skeleton joints and 23 `body_pose` coordinates.

Source: MuJoCo Menagerie `booster_t1` (Apache-2.0).
Assets download automatically; see [asset setup](../index.md#assets).

A manual `model_path` is a directory with `t1.xml` and its meshes.

```python
from robot_models.humanoids.t1.numpy import T1

model = T1()
params = model.get_tpose()
```

Native names are upstream's: `AL*`/`AR*` are the arm links, and the `Elbow_Yaw` hinge in `*_hand_link` is the elbow bend.
