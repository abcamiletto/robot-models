# T1

T1 is the Booster Robotics T1 humanoid. Its skeleton has 24 joints, one per MJCF body, and `body_pose` has 23 hinge coordinates.

## Setup

The assets come from MuJoCo Menagerie `booster_t1` (Apache-2.0). They download on first use from the
[`abcamiletto/robot-models`](https://huggingface.co/abcamiletto/robot-models)
Hugging Face repository, with the upstream license and a list of changes. To prefetch them:

```bash
robot-models download t1
```

A manual `model_path` is a directory with `t1.xml` and its meshes.

## Usage

```python
from robot_models.t1.numpy import T1

model = T1()
params = model.get_tpose()
```

## Notes

Native names are upstream's: `AL*`/`AR*` are the arm links, and the `Elbow_Yaw` hinge in `*_hand_link` is the elbow bend.
